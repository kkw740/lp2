# Ass4 - Event Array + Search Filter

This page shows a JavaScript array of event names and lets you search by keyword.

Files:

- `index.html` — Page layout with search box and list
- `styles.css` — Basic styling
- `script.js` — Array + render + filter logic

## How to open

- Double-click `index.html` to open in your browser, or run:

```powershell
start "c:\Users\sgban\Desktop\LP_2\Ass4 Filter\index.html"
```

## How it works

- We store events in a simple JS array of strings.
- As you type in the search box, we filter by substring (case-insensitive).
- The list updates instantly, and a message shows when nothing matches.

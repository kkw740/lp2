# Ass1 - Static Website (HTML + CSS)

This is a very simple four-page website made with only HTML and basic CSS.

Pages:

- `index.html` — Home
- `about.html` — About
- `events.html` — Event List
- `contact.html` — Contact form (demo only)

## How to open

- Double-click `index.html` to open in your web browser, or
- On Windows (optional), from this folder run:

```powershell
start index.html
```

## How to edit

- Change text directly inside each `.html` file.
- Update colors and spacing in `styles.css`.

## Notes

- This is a static site. No backend or database.
- The Contact form shows a demo alert and does not send real messages.

# Ass2 - Responsive Page (Media Queries)

This assignment makes the Event List page responsive using pure CSS media queries (no Bootstrap required).

Files:

- `index.html` — Responsive Event List page
- `styles.css` — Shared styles with media queries

## How it works

- On small screens (mobile), events are in 1 column.
- From 480px width, it becomes 2 columns.
- From 768px width, it becomes 3 columns.

## How to open

- Double-click `index.html` to open.
- Or from PowerShell in this folder:

```powershell
start index.html
```
